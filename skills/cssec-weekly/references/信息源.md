# 周报信息源

## 政府

政府机构的信息很多，但信息密度可能不高，取用时要保持极度克制。

对政策法规感兴趣的人很少，并且大多数政策的影响普通人并不能直观感受到，因此本周报只取用影响极远极深极快、存在争议、确实有趣的政府信息。

### 中央网信办（中央网络安全和信息化委员会办公室）

官网：https://www.cac.gov.cn

重点关注以下两个页面的信息：

- 网信发布：https://www.cac.gov.cn/wxzw/wxfb/A093702index_1.htm
- 网络安全：https://www.cac.gov.cn/wxzw/wlaq/A093705index_1.htm

### 公安部（中华人民共和国公安部）

官网：https://www.mps.gov.cn

公安部官网的内容大多与网安无关，直接通过安全内参平台的网安局账号获取其信息即可。

公安部网安局在安全内参平台的账户：https://www.secrss.com/articles?author=公安部网安局

### 工信部（中华人民共和国工业和信息化部）

官网：https://www.miit.gov.cn

重点关注以下页面：

- 新闻发布 > 时政要闻：https://www.miit.gov.cn/xwfb/szyw/index.html
- 新闻发布 > 工信动态：https://www.miit.gov.cn/xwfb/gxdt/index.html
- 新闻发布 > 部领导活动：https://www.miit.gov.cn/xwfb/gxdt/index.html
- 政务公开 > 政策文件 > 文件发布：https://www.miit.gov.cn/search/zcwjk.html?websiteid=110000000000000&pg=&p=&tpl=14&category=183&q=
- 政务公开 > 政策文件 > 行政规范文件：https://www.miit.gov.cn/zc/wjxzfl/xzgfxwj/index.html
- 政务公开 > 政策文件 > 文件公示：https://www.miit.gov.cn/zwgk/wjgs/index.html

### 国家信息安全漏洞共享平台（CNVD）

官网：https://www.cnvd.org.cn/

此平台爬虫检测较为严格，可能需要用户手动获取信息。

## 企业

企业平台发布的信息中，可能包含产品、企业文化、企业活动等企业自身信息宣传，一般直接忽略。

### 安全内参（奇安信）

https://www.secrss.com/

此平台内容调性与本报很符合，所以大多数内容直接从这里取。

直接通过如下格式的 URL 获取 JSON 格式的数据，其中 `lastPublishedAt` 为翻页游标（非窗口边界），窗口过滤由客户端按 `start` 日期控制。

https://www.secrss.com/api/articles?lastPublishedAt=2025-09-26 16:43:04&referer=web

## 境外英文媒体（独立信源，补国际事件与一手素材）

> 这些源用于降低对单一中文聚合源（安全内参）的依赖，补国际事件覆盖与一手素材。**均需走代理**——代理由 `scripts/fetch_all.py` 统一处理（地址读环境变量 `CSSEC_PROXY`，默认 `http://127.0.0.1:7897`），无需手工 export；单独调试某个 fetch 脚本时自行设置 `HTTPS_PROXY`。title/summary 透传英文，撰写时译写为中文。

- **The Hacker News** —— https://thehackernews.com/ （RSS: `https://feeds.feedburner.com/TheHackersNews`）
  - 国际事件流主力，高产（CVE / 勒索 / APT / 数据泄露 / 攻击）。
- **BleepingComputer** —— https://www.bleepingcomputer.com/ （RSS: `https://www.bleepingcomputer.com/feed/`）
  - 深度报道，常含厂商博客 / PoC 等一手链接入口，是头条纵深补强关键源。
- **Krebs on Security** —— https://krebsonsecurity.com/ （RSS: `https://krebsonsecurity.com/feed/`）
  - 独家深度调查（地下产业链、欺诈、APT 起底），量小重磅。
- **Dark Reading** —— https://www.darkreading.com/ （RSS: `https://www.darkreading.com/rss.xml`）
  - 企业安全视角，与 THN 互补（偏企业运营而非纯事件）。
- **Schneier on Security** —— https://www.schneier.com/ （RSS: `https://www.schneier.com/feed/`）
  - 观点 / 趋势 / 密码学 / 隐私分析，作「前沿技术 / 政策法规」判断锚点。

## 取用规则（该取 / 不该取）

三层取舍（政府极度克制 / 企业剔除自宣 / 社区甄别真伪）的**执行规则见 `../SKILL.md`「取舍规则」**，决策理由存档见 `设计规格.md` §2，此处不再重复。与源相关的两条操作约束：

1. **跨源去重**：英文源与安全内参同事件的合并为一条，优先保留英文一手链接作出处。
2. **社区时效**：CTFtime 赛事按时间窗筛「即将举办/进行中」，`POSTPONED`（延期）需标注。
