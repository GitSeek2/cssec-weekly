# 交付前自查速查卡（纯判断项）

> 本卡只保留**机器检不了的判断项**。所有可计数检查（红线禁令、引语溯源、零件齐全性、链接追溯、句长与标记配额）由 `../scripts/lint.py` 机检——**lint 退出码 0（error=0）是交付的前置门禁**，本卡在其之后人工复核语义与语感。文风原理见 `写作风格.md`，流程与取舍见 `../SKILL.md`。

## 〇、机检门禁（先过这个）

- [ ] `lint.py <成品.md>` 退出码 0（error 级全部清零；warning 级按朗读感受酌情处理）。

## 一、结构与选题

- [ ] 非安全方向学生也能读懂——专业概念有解释，无未加说明的术语。
- [ ] 政府信息已克制筛选；企业自宣已剔除；社区信息已甄别。
- [ ] 无料的板块已省略，未硬凑；板块内常规简讯与一句话短讯搭配，版面有大小配。
- [ ] 头条突出：篇幅与深度明显高于板块条目，且至少 1 条一手素材。

## 二、新闻动作（lint 只数数量，这里验质量）

- [ ] **归因抽查**：随机抽 3 条简讯，遮住出处行——每句话的来源仍能从句内辨出（据 X 通报 / X 表示 / X 披露）。
- [ ] **引语质量**：头条 2~4 处引语全是"说机制/说事实"的原话（无表态度空引语、无改写后加引号）；说话人首现有姓名+职务。
- [ ] **人物动作**：头条叙事线至少一处完整人物动作链（谁、何时、做了什么、导致什么）；叙事段主语常是人不是"系统/问题"。
- [ ] **标题抽检**：随机抽 3 个 H3，每个都含具体动词 + 影响/数字，无名词目录式标题。

## 三、叙事与语感

- [ ] 每条可独立扫读（标题 + 首句即可判断是否细读）；导语是最硬的事实，倒金字塔成立。
- [ ] 头条五段成链：一句话链在成稿中成立，段间是推进不是并列，上段落点被下段起点接住。
- [ ] **朗读一遍**：无翻译腔、无连续三句同构；长短错落，短句可以成段；拗口处已拆或改。
- [ ] 结尾三式之一（硬事实 / 引语 / 悬空式），无空建议、无趋势判断、无"综上所述"。

## 四、编辑终审与事实核查（阶段五、六必须走完）

- [ ] 已切换审稿人身份独立重读，未为任何一句辩护；头条走完 `审稿.md` 五步。
- [ ] 审稿记录已落盘 `sources/审稿记录.md`；事实、数字、引语、出处未被终审改动。
- [ ] `check_facts.py` 的 unmatched 已逐条裁决并落盘 `sources/事实核对.md`。

## 五、HTML / PDF 版自查（阶段八生成后核对）

- [ ] `issues/<dirname>/<filename>.html` 已生成，与 `<filename>.md` 同目录同名；单文件 CSS 全内嵌；`file://` 打开零报错。
- [ ] 内容与 `<filename>.md` 逐项一致：报头刊号、导读、头条各小节、各板块条目、赛事数据行、相关文献、下期预告、反馈入口、AI 撰写说明。
- [ ] 主题色 `#016737` 生效（版眉绿竖条、头条标记、导读/预告左绿边）。
- [ ] `<filename>.pdf` 已生成：A4、无浏览器默认页眉页脚、正文完整；打印预览分页合理（标题不孤行、导读/文献/表格不跨页断块）。
- [ ] 错误路径已验证：脚本异常时退非 0、stderr 有报错（不静默失败）。
