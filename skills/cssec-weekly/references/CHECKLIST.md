## 四、删除清单（grep 自查，四类 AI 思维错误）

> 头条段③矛盾与纵深、段⑤落点允许「有信息量的诚实判断」（判据见 `写作风格.md` Part 3 段③四判据：可证伪 / 机制非口号 / 指明条件对象失效点 / 可复述）。下列四类是**修辞废料**，与诚实判断无关，仍全部删除。

- [ ] **A 类 向上提炼**：无「这意味着 / 这说明了 / 再次说明 / 再次印证 / 是……的缩影 / 一张……背后」。
- [ ] **B 类 替读者思考**：无「把视角拉远 / 纵观 / 换句话说 / 值得注意的是 / 需要警惕的是 / 既是……也是……」；无反问句收尾；无设问式小标题（小标题用名词性短语）。
- [ ] **B 类 喊话读者**：无「对学生来说 / 作为安全从业者 / 我们应该 / 你需要关注」。
- [ ] **C 类 修辞代替事实**：无比喻、拟人、对仗；无「不是 X 而是 Y」对比句式；无「这不是演习 / 真正的考验刚刚开始」惊人句式。
- [ ] **导语**：头条第一段是具体事实（反常细节/数字/被打破的常识），非「随着……发展 / 近年来 / 本周动态频繁」式开门。
