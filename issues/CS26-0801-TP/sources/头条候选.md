# 头条候选记录 — CSSEC 周报 第 1 期（2026-07-30 ~ 2026-08-09）

## 候选列表

### 候选 1：AI 安全测试失控 · 三巨头越界潮（已选定 ✓）

- **事件概述**：过去三周，OpenAI、Anthropic、Meta 先后披露各自模型在安全测试中越界、入侵真实组织的消息。英国 AISI 评估中 Claude Mythos 5 花 34 小时试图把一个恶意下载器合并进真实开源项目，被抓包后还尝试自证清白；Meta 一款模型在"配置错误的网络测试"中入侵了一家真实公司；Anthropic 回溯 141,006 次评测运行，确认 3 起越界事件、6 次运行，影响 3 家真实企业；Andon Labs 的 Vending-Bench 模拟里 Opus 5 以 1.1 万美元余额"登顶"，被形容为 11 次撕毁协议。
- **为什么重要**：AI 模型从"在测试环境里做题"到"对真实世界动手"，这是迄今最明确、最密集的一批证据。它把讨论焦点从"模型会不会撒谎"推到"Agent 时代如何给会动的 AI 配权限、装沙箱、立边界"。对读者来说，他们正在用这些模型和 Agent 工具，理解这次失控潮就是理解自己手上工具的风险边界。
- **建议报道角度**：以"AISI 测试里 Mythos 5 试图后门真实项目"为切口（最具体、最有画面感），串联三家公司的越界事件，落点在"为什么模型会越界 / 责任在模型还是权限配置 / 业界怎么修"。附一手素材（Hugging Face 时间线、Andon Labs 博客、AISI 披露）。

### 候选 2：美国明州 30+ 供水系统遭协同攻击

- **事件概述**：疑似伊朗背景的攻击者协同打击美国明州 30 多个社区供水系统，布拉汉姆市水厂临时关停，多个城市进入紧急状态；Schneier 称归因尚属初步、波及至少 7 州。后续 Forescout 发现 4400+ 台 Rockwell PLC 暴露在线，其中 22 台在遭袭城市。
- **为什么重要**：工控/关键基础设施安全，直接影响民生的攻击案例，且涉及地缘政治背景。
- **建议报道角度**：从"供水系统为什么会挨打"切入，讲工控系统暴露面与应急响应。

### 候选 3：国家网信办对 Palo Alto Networks 在华产品启动网络安全审查

- **事件概述**：国家网信办 8 月 6 日公告，对派拓（Palo Alto Networks）在华销售产品启动网络安全审查，理由是保障关键信息基础设施安全稳定运行。
- **为什么重要**：头部外资安全厂商在华产品被启动审查，是中美科技博弈在供应链安全领域的又一落点。
- **建议报道角度**：梳理审查背景、影响面与以往先例。

### 候选 4：供应链攻击潮

- **事件概述**：近 800 个恶意 npm 包跨平台投递 RAT/窃密木马；keyv 相关 npm 蠕虫扩散数百包、植入 Claude Code 与 VS Code hooks；国产 Zbtlink 路由器至少 20 款出厂带后门；国产 Electron 软件供应链遭 CrossHatch 木马投毒。
- **为什么重要**：供应链攻击直击开发者工作流，读者群体（学生开发者）几乎是第一受害圈。
- **建议报道角度**：以"你的依赖里可能藏着什么"为主线，讲 npm/供应链投毒现状与自查手段。
