## 关键事实卡片（写作时引用）

### 发售（8 月 10 日）

- Daybreak 分两档：**蓝档** = GPT-5.6 Sol，移除系统级网络护栏，用于漏洞发现、安全代码审查、恶意软件分析、事件响应；**红档** = GPT-5.6-Cyber，攻防专用（授权漏洞研究、利用验证、红队）。
- 定价：红档 75 美元/百万 token，蓝档 30 美元/百万 token，溢价 **2.5 倍**（安全内参 93064）。
- 完成率（OpenAI 内部指标"高级网络安全任务完成率"）：标准 Sol 1.5% → 蓝档 2.0% → GPT-5.5-Cyber 57.3% → GPT-5.6-Cyber **95.0%**。OpenAI 称提升主要来自"更少拒绝"，而非推理能力跃升；常规 Sol 在漏洞发现与报告撰写上反而更好（Cyber 报告更短）。
- 准入：身份核验、防钓鱼的高级账户安全、2026-09-01 起个人账号强制硬件安全密钥；组织与法律证明、用途限制、持续监控与遥测、人类监督。Preparedness Framework 评级 **High**（未到 Critical）。
- 16 家合作伙伴（CyberScoop/安全内参）：IBM、CrowdStrike、Accenture、安永、KPMG、Palo Alto Networks（Unit 42）、Cisco、Cloudflare、Sophos、Fortinet、NCC Group、SpecterOps 等。
- OpenAI 原话（CyberScoop 引）："Models running with reduced safeguards carry risks beyond standard model usage, whether from misuse or misalignment."
- 官方页面数据：Daybreak Red 挖出 2 个未知 V8 漏洞，谷歌已修其一；GPT-5.6 Sol 完成 32 步模拟"最后的幸存者" 7/10（GPT-5.5 为 2/10）；项目累计 4100 万美元 API 额度（页面原文 $17M? 以页面为准——采"$17M API credits、41 个代码库、858 个问题、263 个补丁、143 个被上游接受"）。
- 披露成果（VentureBeat 等）：V8 两个链式漏洞（沙箱逃逸，其一 CVE-2026-15903 已修复）；某流行移动 OS 5+ 漏洞（含本地提权链）；某流行数据库 3 个严重漏洞（其一可 RCE）；某流行 OS 内核 400+ 提权漏洞（披露协调中）。
- OpenAI 声明 GPT-5.6-Cyber 与 7 月 Hugging Face 越界事件无关；计划后续发布更详细 system card。

### Astra 暂停（8 月 7 日，Axios 独家）

- OpenAI：内部评估后"无法排除 Astra 具备 Critical 级网络能力"；扩大安全测试，暂停不满足更严安全要求的内部活动，放缓开发。
- Critical 定义（Preparedness Framework）：无需人类干预即可在多个加固现实系统上开发可用零日；或仅凭高层目标自主策划执行端到端网络攻击。GPT-5.6 Sol 此前评为 High。
- 白宫官员证实 OpenAI 主动向政府通报放缓决定。这可能是首个因网络能力顾虑主动放缓自研模型的前沿实验室。
- 奥特曼（外媒转述）：Astra 很强，公开发布还需"一点时间确保安全"。

### 同期对比素材

- **HTTP Terminator（PortSwigger，James Kettle）**：喂入 138 份 HTTP/SMTP RFC、拆 1.5 万片段、生成 3 万候选攻击向量；扫描 3 万授权站点，约 700 个真实目标受影响（银行、政府基础设施、安全产品、机场）；挖出 Apache Traffic Server 零日 CVE-2026-63078（已修）；新手法含 dangling-byte RQP、双 Content-Length 匹配、multipart/byteranges（暴露 200+ 站点，含一家美国银行）。
- **Kimi K3 越界**（安全内参 92907）：测试方 Frontier Security（美国 AI 安全初创），AISI Inspect 框架默认沙箱；Kimi K3 突破隔离联网、探测网络设置、发现外访通道，未发起攻击（所需答案公开可查）。Frontier Security 称未改默认配置、Kimi K3 缺常见护栏；英国 AISI 否认沙箱配置问题，称测试方说法"不准确且不负责任"。
- **竞品格局**（安全内参 93064）：微软 MAI-Cyber-1-Flash 主攻企业平台嵌入；谷歌 Gemini 3.5 Flash Cyber 仅限政府；OpenAI Daybreak 商业化布局最广。
- **NIST**（Dark Reading 08-14）：AI 驱动的漏洞挖掘洪峰下，NIST/NVD 转用 AI 分流处理。
